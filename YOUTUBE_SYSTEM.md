## YouTube Channel Branding — Complete Service Breakdown

This is the full scope of what this studio delivers for YouTube channel projects:

### 1. Channel Identity System
- Channel name strategy and positioning

- Color palette (optimized for screen/video)

### 2. Channel Art Package
| Asset | Dimensions | Notes |
|---|---|---|
| Channel banner | 2560 × 1440px | Safe zone: 1546 × 423px center |
| Profile picture | 800 × 800px | Displayed as 98×98px circle |
| Watermark / branding | 150 × 150px | Overlaid on videos |
| About/description | Text | SEO-optimized channel description |

### 3. Thumbnail System
The thumbnail is the most important visual asset for channel growth.

**Template types**:
- Hero shot (character/person dominant)
- Text-heavy (bold title + supporting image)
- Comparison (before/after, A vs B)
- Question/curiosity (incomplete visual)
- Series template (consistent for playlists)

**Design rules**:
- Readable at 168×94px (mobile grid size)
- Max 3 elements: face/character + text + background
- Consistent brand elements (color, font) across all thumbnails
- A/B test: CTR is the key metric (benchmark: 4–10% is good)

### 4. Video Template System
- Intro animation (5–15 seconds)
- Lower thirds (name, title, social handles)
- End screen layout (2 video suggest boxes + subscribe CTA)
- Cards template
- Chapter markers style

### 5. Playlist Architecture
- Series naming convention
- Playlist cover art (same ratio as thumbnails)
- Category grouping strategy
- Evergreen vs. trending content balance

### 6. Content Architecture
- Publishing schedule framework
- Content pillars (3–5 topic categories)
- Title formula library (curiosity gap, how-to, list)
- Tags and metadata strategy
- Community posts calendar

### 7. Cross-Platform Extension
- Shorts/Reels adaptation of thumbnail system
- Instagram grid aesthetic (matches YouTube branding)
- TikTok overlay style
- Podcast cover art (3000×3000px, if applicable)

## YouTube SEO for Channel Clients

### Title Formula Library
- `How to [achieve result] in [timeframe] — [qualifier]`
- `[Number] [things] that [outcome]`
- `Why [common belief] is wrong (and what to do instead)`
- `[Topic]: The complete [beginner/advanced] guide [year]`
- `I tried [challenge] for [time] — here's what happened`

### Description Template Structure
```
[Hook — 1–2 sentences, repeat title value prop]

[What this video covers — 3-5 bullets]

[Timestamps/Chapters]

[Call to action — subscribe, comment prompt]

[Playlist links]

[Social links]

[Hashtags — max 3 relevant ones at bottom]
```

### Tags Strategy
- 5–8 tags per video
- Mix: broad (high competition) + specific (long-tail)
- Include channel name as one tag
- First tag = exact match of primary keyword

## YouTube Brand Projects: Workflow

### Discovery Phase (Week 1)
1. Channel audit (if existing): current performance, top videos, thumbnail CTR
2. Competitive analysis: 5–10 similar channels
3. Target audience definition
4. Brand positioning: what makes this channel different
5. Style direction moodboard (3 options)

### Design Phase (Weeks 2–3)
1. Logo concepts (3 directions)
2. Color system
3. Typography selection
4. Channel art first draft
5. Thumbnail template (2–3 templates)

### Production Phase (Week 4)
1. Final logo + all formats
2. All channel art assets
3. Full thumbnail system (5–8 templates)
4. Brand guidelines PDF
5. Video intro animation (optional)

### Delivery + Training (Week 4–5)
1. Asset delivery (Google Drive or WeTransfer)
2. Figma/PSD template handoff
3. Brand usage walkthrough
4. First 5 thumbnails produced by studio as examples
